# AI Declaration

Generative AI (genAI) tools were used during the development of this project.

The main areas where genAI assisted were:

- **Code debugging** — identifying and fixing errors in the Python/Flask backend.
- **HTML setups** — scaffolding and structuring the Jinja2/HTML templates.
- **SQL queries** — drafting and refining database schema and queries.
- **Docker configuration** — setting up the Dockerfile and docker-compose.
- **Documentation** — drafting the README and inline comments.

All AI-assisted output was reviewed, tested, and adapted by the author before
being included in the project.
